# Quantify：个人股票量化研究 demo

Python 3.10+，**零第三方依赖**。个人本地工具，无账户、无自动交易；研究工作台使用 Python 内置 SQLite 保存数据和实验。
重点是检验因子在样本外是否改善结果，同时保留基本面、估值和风险分析。没有“保证胜率提升”的功能。

后续建设以 [构建计划](docs/BUILD_PLAN.md) 为准，覆盖真实数据接入、因子版本管理和 ChatGPT 辅助迭代；每次开发记录在 [迭代目录](docs/iterations/README.md)。CSV 数据中心、因子版本和实验记录已实现；在线真实数据和 ChatGPT 接入仍待后续阶段。文档维护约定见 [docs 入口](docs/README.md)。

## 研究工作台（第一阶段 CSV 路线）

启动后从首页点击“进入研究工作台”。原有个股、估值和合成研究页面继续保留。

1. 数据中心支持日线、月度面板、财务因子与历史股票池 CSV，下载表头模板后填写自己的数据；没有数据时可点击“创建合成研究快照”体验流程。
2. 导入时声明来源、复权/分红口径与数据性质。选择父快照可以增量更新；重复数据不重复入库，修订保留旧版本。
3. 因子库提供五类基线，可以派生新的窗口/跳过月份版本，并记录修改理由。
4. 实验选择月度快照及具体因子版本，统一训练/测试时段，封存末尾至少 12 个月，保存成功与失败记录；支持对比、复现和完整 JSON 下载。
5. 有完整含分红指数时，可从日线生成月度快照，并按历史可用日期连接财务与股票池。仅有原始价格时不猜测总回报。

数据保存在默认的 `runtime/research.sqlite3`（已忽略，不提交 Git）。可用 `python app.py --data-dir /your/data/directory` 或 `QUANTIFY_DATA_DIR` 指定位置。备份时先停止程序，再复制整个数据目录。

字段契约、样本量要求、时点规则和备份说明见 [数据契约](docs/DATA_CONTRACTS.md)。默认封存 12 个月时，工作台 3/6/12 月持有期分别至少需要 86/92/104 个月数据，建议更多。旧首页研究仍采用原先窗口，不会与工作台得到相同测试起点。

**目前没有在线行情或真实数据覆盖验收。** CSV 的来源与可用时间由用户声明；股票池历史事件可查询，但动态股票池研究、退市结算、组合成交、自动每日下载和 AI 调用仍未实现。实验为固定池单笔收益研究，不是组合净值回测。

## 使用

1. 选择湖南裕能、容百科技、豪威集团、均胜电子或中国平安。所有公司数值均为**人工合成**，公司名称仅作示例标签，不代表真实经营情况。
2. 因子研究先运行合成面板了解流程，或下载模板、导入自己的 CSV。研究不依赖下方基本面或模拟。对比筛选组/基准的上涨比例、平均持有期收益、最差单笔收益和样本量，再检查各测试窗口稳定性。
3. 编辑悲观/中性/乐观利润与 PE。保险另支持 EV 与 P/EV。每项假设说明可编辑；无情景权重或概率。起点价和总股本也可修改。
4. 编辑 GBM 年化价格漂移、波动率、股息率、路径数及种子，计算风险。切换 3/6/12 个月和价格/总回报口径。修改输入会隐藏旧结果，需重新计算。
5. 导出 JSON 或 CSV。CSV 为 `field,value` 长表，包含完整输入、来源、单位、口径、模型参数、统计及直方图；JSON 更适合后续程序读取。文件在浏览器本地下载，不自动保存到服务器。

## 基本面与估值

工业企业展示三年营业收入、归母及扣非利润、经营现金流、资本开支、存货、债务、现金、总资产负债和归母净资产。派生指标包括同比、现金流/利润、扣非/利润、简化自由现金流、负债率、净有息负债、PE/PB。
保险使用归母营运利润、NBV、集团 EV 和寿险主体偿付能力指标；不套用工业企业库存指标。指标主体边界在数据中说明，不能直接用来判断监管达标。

金额统一为亿元人民币，股本为亿股，目标价为元/股：

```text
目标价 = 归母净利润 × PE / 总股本
保险备选目标价 = 内含价值 EV × P/EV / 总股本
价格收益 = 目标价 / 用户输入的起点价 - 1
```

非正利润/EV 返回“不适用”，不输出负股价。估值情景为用户假设的未来12个月；不含分红，不赋予概率。
基本面派生估值使用原始演示快照的价格与股本，用户修改的起点只影响情景，UI 有明确标识。PE 使用最近合成年度归母利润，**不是实时 TTM PE**。
同比在上期非正时不计算。简化自由现金流为经营现金流减资本开支。所有比率仅用于观察，不合成为评分。

## 模拟方法与限制

模型 `GBM / daily exact log increments / v1`，252个交易日/年，3/6/12个月 = 63/126/252日。同一批路径的三个时点保证触及事件口径一致。

```text
dS / S = μ dt + σ dW
S(t+dt) = S(t) exp[(μ − σ²/2)dt + σ√dt Z]
价格收益 = S(t)/S(0) − 1
含分红总回报 = S(t)/S(0) × exp(qt) − 1
```

μ 是年化**价格**漂移，q 为恒定连续股息率，不从 μ 再减 q。分红即时再投资，未计税费或离散除息。起点是不复权合成价格，模型在相对指数上模拟；不能直接将后复权真实序列收益再叠加股息以免双计。

模型输出均值、P5/P25/P50/P75/P95、期末上涨/下跌/持平概率及相对初始投入触及 −10%/−20%/−30%/−40% 的概率。数值绝对误差在 1e-12 内视为持平。直方图覆盖所有终值。

触及按每个交易日收盘判断，包含初始点，**不是最大回撤，也不是连续/日内触及**；可能低估连续触及概率。价格与总回报分别判定。
参数均为可编辑假设，默认值非历史拟合，**未经校准**。最大蒙特卡洛标准误差 `0.5/sqrt(N)` 只是抽样噪声，不包括模型误差；0%/100% 不意味着不可能/必然。无跳跃、厚尾、波动聚集、涨跌停、停牌或流动性约束。

公式参考：[University of Queensland Monte Carlo 讲义](https://people.smp.uq.edu.au/DirkKroese/mccourse.pdf)。此参考是数学背景，未作为公司数据或校准来源。

## 因子研究：历史频率与模拟概率分开

候选因子：6个月含分红动量、用户给定盈利质量、用户给定估值收益率等价值因子、6个月低波动，以及四因子截面排名的等权组合。quality/value 越大越好；组合百分位**不是概率**，也不是历史估值分位。

滚动流程：36个月训练窗中仅使用已实现、退出日严格早于测试信号的标签，选择历史上涨比例最高的候选规则；固定规则进入12个月测试块。训练标签会重叠，测试持有区间按3/6/12个月分隔、无重叠。训练数据不足/标签未成熟的行被剔除，实际训练信号数可能少于36。
信号使用观察时点及之前数据，下一月观察点入场，持有指定月数再退出。并非月末同价即时成交。
收益 = 含分红指数比值 − 1 − 往返成本，成本单位 bp（1 bp = 0.01%）；默认20 bp。选股与全池基准在相同日期、持有期和成本下比较。

统计单元是“股票 × 入场月份”，不是独立试验或组合净值。上涨比例为扣除上述成本后收益 > 0 的比例。股票间相关，不展示会造成精确错觉的独立二项分布置信区间。平均收益按单笔等权算术平均，不年化、不复利。单笔最差收益不是持有期最大回撤。

合成研究面板为5个虚构代码、2017-01至2025-12的108个月，不对应上述五家公司；没有刻意植入因子预测能力，改善可能为负。示例结果不能证明实际胜率提升。
导入格式（严格保持表头顺序）：

```csv
date,symbol,total_return_index,quality,value,available_at
2017-01-01,DEMO1,100.0,0.12,0.07,2016-12-31
```

- UTF-8、最大1.5 MB；60–600个月、3–100只股票，每月一个截面，月份连续，各月股票池一致。12月持有期至少68个月才有首个结果，建议72个月以上。
- `date` 为观察日期；`available_at` 为该行财务因子均已可用的最晚日期，不得晚于观察日。价格指数在观察时点收盘可用。程序只校验声明日期，无法验证财报真伪。
- `total_return_index` 为正的**含分红再投资指数**（任意一致基期、无货币单位）；不允许直接以不复权股价替代。分红不可再重复添加。拆股与公司行动应由数据源处理。
- `quality`、`value` 为无量纲原始因子（如现金流/利润、盈利收益率），同月跨股票可比。负值允许，不允许 NaN/Infinity。UI 要求填写来源与复权/分红口径；导出保留该声明、原始CSV（包括逐行时间）、单位及SHA-256摘要，便于复现。
- 平衡面板要求会带来幸存者偏差风险；不要通过静默删除退市股票解决缺行。首版不适合将真实研究结论直接用于投资，需完善动态股票池和退市收益。
- 没有独立最终留出集、概率校准、组合资金核算或真实成交模型。优化训练上涨比例有选择偏差；需要检查平均收益和尾部，不能宣称“找到稳定高胜率”。
