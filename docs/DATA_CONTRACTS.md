更新日期：2026-10-14（Asia/Shanghai）。适用于迭代 001。真实数据源尚未接入；用户选择先建设 CSV 导入与可替换接口。

## 导入入口与共同规则

启动 `python app.py`，从首页进入“研究工作台”，在数据中心上传 UTF-8 CSV。下载的模板只有表头，不包含伪装成真实行情的数据。

- CSV 表头和顺序必须完全匹配下方契约。单次最多 8 MB、100000 行；单字段受标准库 CSV 解析上限约束，超长字段拒绝。
- 日期统一 `YYYY-MM-DD`，采用中国市场日期。代码允许字母、数字、点、下划线和短横线；推荐 `600000.SH`、`000001.SZ`。合成数据可以使用 DEMO 代码。
- 必须声明来源、价格口径、是否演示数据。前复权、后复权、不复权 OHLC 与含分红收益指数分别记录，程序不替用户推算公司行动。
- 数值必须有限，拒绝 NaN、Infinity、重复键、列数不一致、无效日期和不合理 OHLC。
- 输入乱序会规范排序并附质量提示，原始输入保留。
- 日线和财务可用日期不能早于行情日/报告期。当前为日期粒度，不具备盘中公告时间或实时事件顺序精度。
- 数据库位于 `runtime/research.sqlite3`，运行数据已加入 Git 忽略；可用 `--data-dir` 或 `QUANTIFY_DATA_DIR` 指定位置。

## 日线行情 daily

```csv
date,symbol,open,high,low,close,volume,total_return_index,available_at
```

- `open/high/low/close`：同一声明口径的价格，通常元/股；必须大于零且 low ≤ open/close ≤ high。
- `volume`：股，不能直接传入以“手”为单位的数值，须在提供商适配层转换。
- `total_return_index`：正的含分红再投资指数，无量纲且基期一致。可为空；为空时允许保存和检查日线，但拒绝转换成总回报研究面板。
- `available_at`：该版本日线可用于研究的日期，按当日收盘之后解释。迟到或修订数据必须如实标记。读取旧数据版本需要使用旧快照。
- 价格口径可选 `unadjusted`、`forward_adjusted`、`backward_adjusted`、`total_return_index`；最后一项仅在 OHLC 本身确实为相应指数时使用。

尚无交易日历核验，因此缺失交易日、停牌、涨跌停、退市及公司行动完整性只会提示未验证，不会声称数据齐全。

## 月度面板 monthly

```csv
date,symbol,total_return_index,quality,value,available_at
```

- 每月一个截面，3–100 个固定股票代码，月份连续，最多 600 个月。研究引擎规范化后的 CSV 仍受 1.5 MB 上限约束。
- `quality/value` 是用户计算的无量纲财务因子，数值越大越好，不是利润原值或 PE 本身。两列可留空，但只能选择动量/低波动版本。
- `available_at` 为所用财务因子已可用于该观察日的日期，不能晚于观察日。原始月度导入不执行公告时刻核验，盘后公告必须由提供者滞后处理。
- 固定池有幸存者偏差风险。缺少股票、退市收益或月份时不得通过静默删除满足面板条件。
- 工作台统一使用 30 个月因子预热以公平比较窗口不同的因子，训练窗 36 个月、测试块 12 个月、次月观察点入场。相较首页原有 demo，测试起点会更晚。
- 工作台至少封存末尾 12 个月。总月数至少为 `68 + 2 × 持有月数 + 封存月数`；封存 12 个月时，3/6/12 月持有期分别至少需要 86/92/104 个月。建议使用更长历史。
- 留出期不进入本次收益计算或报告内开发 CSV；原始快照仍可由本地用户查看，因此这不是权限隔离，也不是已完成最终独立验收。后续 AI 接口需遵守留出访问规则。

## 财务因子 financials

```csv
period_end,symbol,quality,value,available_at
```

财务记录按报告期、代码和可用日期识别。`available_at` 表示该版本因子依据的公告可用日期，修订使用新的日期。相同可用日期而数值冲突的记录拒绝增量覆盖。

时点查询先排除未来报告期和不可用公告，再选同一报告期的最后已知修订。由于只有日期，财务公告在公布日当天保守视为未知，从之后的观察日才使用。日线转月度时，按股票取最近已知报告期；缺失时不填零、不回填未来财报。

这些列是财务因子输入，不是完整财报数据库；尚未计算行业可比财务指标、核验公告来源或处理所有会计口径差异。

## 历史股票池 universe

```csv
date,symbol,member,available_at
```

`date` 是成员事件生效日，`member=1` 加入、`member=0` 退出；必须提供初始成员事件。查询时同时检查生效日期和可用日期，返回当时已知的事件，不将未来成分调整提前使用。

目前已支持事件存储、修订和历史查询；月度转换遇到成员变化会拒绝，动态池收益评估、退市结算仍需后续建设。不能将这个存储接口描述为已完成动态股票池回测。

## 快照与增量语义

- 内容摘要标识不可变快照，包含元数据、规范化行、原始导入文本与父版本关系。
- 增量更新需选择父快照，来源、类型、口径与演示标识必须相同。
- 重复导入且没有数据变化时返回父快照；新行合并；日线/月度相同键修订会生成新版本，旧快照保持原样。
- 财务/股票池修订通过新增可用日期保留历史，不能在同一历史可用日期覆盖不同内容。
- 校验完成后才进行 SQLite 事务写入；失败没有半个快照。重试同一父版本和相同输入可得到相同快照。
- 历史版本是分支式的；更新必须明确选择父快照，程序不自动合并两个分支，也不删除旧版本。

## 日线转月度

选择日线及可选财务、股票池快照后转换：

1. 按各月最后一个观测日期取所有需要股票的同步截面，不使用停牌股票的陈旧价格。
2. 没有交易日历，不能证明该日期是真正月末交易日；舍弃最后一个日历月并保留这个限制。来源仍需提供完整日线。
3. 检查含分红指数存在、行情当时可用；财务按当时已知版本连接。
4. 若提供股票池，使用当时成员；成员变化则拒绝进入当前平衡面板研究。
5. 保存新的月度快照和全部来源快照 ID，不改写原始数据。

## 可替换接口

`ResearchDataAdapter.read(kind, raw)` 返回规范化行与质量提示；`CSVDataAdapter` 为当前实现。外部来源适配器负责授权访问、下载、分页、单位转换与口径说明，再进入同一导入/校验/快照服务。下载和存储解耦，因子不引用供应商字段或网络接口。

## 备份与恢复

先停止应用，再备份整个数据目录；恢复时使用对应代码版本、Python 版本和备份目录启动。不要在写入事务中仅复制主数据库文件。快照 JSON 可下载作审计材料，当前尚无整库 JSON 恢复入口。

实验保存请求、因子版本、快照 ID、计算源码摘要、Python 版本、确定性标记和随机种子（当前确定性计算为 null）。代码指纹改变时拒绝声称原环境复现；可恢复对应代码后复算，或创建标注为新版本的实验。
