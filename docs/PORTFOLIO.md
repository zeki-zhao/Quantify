# 组合账本与开发期回放

迭代008，2026-10-16（Asia/Shanghai）。入口 `/portfolio`。生产运行仍只有 Python 标准库，无券商连接。

## 使用步骤

1. 没有真实数据时点击“准备合成账本示例”：生成固定种子的五股日线、执行状态、月度价格快照、动量开发实验和组合版本。该工作日日历仅为合成流程，不能解释为真实交易日或投资表现。
2. 在版本表“提交回放”，后台任务完成后查看筛选组合与等权全池的净值、现金、持仓、费用、回撤和成交。可导出完整双账本 JSON，按固定版本重新回放。任务页与本页支持取消和新建重试，关闭页面不停止计算。
3. 使用自己的数据时，在工作台导入未复权 `daily` 和开盘前 `execution` 状态，日线生成 `monthly_price`，再完成开发实验。组合页选择该实验及其中一个因子、日线和状态；数据性质必须一致。
4. 修改选股数、初始资金、1/3/6/12月调仓周期、目标现金比例或费用时保存新版本，可注明父版本；旧版本不变。单笔研究的往返成本不直接转换为组合成本，本页另行固定逐笔佣金、最低佣金、卖出印花税、双边过户费及滑点。

源实验必须属于当前引擎。代码摘要变化后旧结果仍可查看，但新提交/复现会拒绝旧引擎版本；需要重跑开发实验、再创建组合版本。组合版本保存源实验、因子、三类数据快照、父版本、参数与引擎，结果单独不可覆盖留档。

## 数据和时间边界

- 只接受月度未复权价格面板，含分红指数不能当成交价。价格为元/股、0.01元单位，成交量为股。
- 真实来源声明的代码先覆盖 `60xxxx.SH`、`00xxxx.SZ`、`30xxxx.SZ`。科创板、北交所和其他品种的交易单位尚未支持；合成示例单独标识。
- 月度面板必须与绑定日线的同期收盘一致。回放每个观察日必须有固定池完整日线和逐股执行状态，不补价、不删股、不将缺失状态当可成交。
- 状态 CSV 见[数据契约](DATA_CONTRACTS.md)。`available_at <= date` 表示导入者声明状态在该日开盘前已知；日期粒度无法核实盘中获知顺序。日线当日收盘可用，开盘执行只取其 open，收盘只用于当日估值和之后信号；迟到的日线拒绝回放。
- 停牌须显式提供零量、OHLC相等的估值栏（由来源声明估值），不会成交。非停牌零量、OHLC超出声明限价、缺少限价或不合理价格拒绝回放。
- 起点固定为源实验第一个测试信号日，终点固定为开发窗末日；末尾留出区间不进入分值、执行或收益计算。

本轮是固定因子的**开发窗探索性回放**。因子及其参数可能已经用整个开发窗选择，故不能称为独立样本外组合验证；也不复现原单笔研究每窗更换因子的策略。原 `/strategies` 的独立单笔最终验收不赋予此组合启用资格。本轮没有组合最终验收、自动准入或AI工具读取组合报告。

## 调仓与成交规则

1. 月度信号收盘后，用该时点及以前的月度输入计算固定因子，分数降序、同分代码升序选前K。等权全池参照独立核算，使用相同起止、资金和执行假设。
2. 目标资金 = 信号日权益 × (1 - 目标现金比例)。各股票均分目标资金，按信号日收盘价向下取100股整数手；减去当前持股得到固定订单股数。目标现金比例为调仓目标，不是执行后现金硬约束。
3. 在下一条日线观察日开盘，先卖再买，同侧按代码排序；未来开盘价不会扩大订单。买入跳空或费用导致资金不足时，只减少为可支付整手或拒单；部分成交的剩余量取消。不会加杠杆、卖空或延续追单。
4. FIFO 持仓批次，只有取得日期早于执行日的股数可卖（T+1）。100股整手限制同样用于卖出；暂不处理公司行动产生的零股。
5. 停牌拒单；买入遇开盘或滑点后价格达到涨停拒单，卖出遇跌停拒单。反向买跌停/卖涨停允许模拟，但不保证真实有对手盘。
6. 不利滑点加在开盘价上：买入向上、卖出向下，按0.01元向不利方向取整。滑点是一种成本假设，可能超出当日实际可成交的盘口范围；没有成交量参与率、排队和盘中撮合。滑点金额已包含于成交价，不再次从现金扣除。
7. 佣金 = max(按成交额计算的佣金，单笔最低佣金)，过户费双边、印花税仅卖出；每项按分四舍五入。默认值只是固定用户假设，不会按历史日期自动切换税率。
8. 每个观察日按收盘估值。终点保留现金与持仓，不强制清仓，也不扣尚未发生的退出费用。最后信号若无下一条日线，订单明确记为未执行。

无真实交易日历核验，周末数据拒绝，但无法发现所有缺失交易日或把节假日识别正确。下一条日线仅称“下一观察日”，不保证下一交易所交易日。缺失停牌估值栏时应先补来源声明，不能直接跳过该股票。

## 指标与对账

内部金额使用 Decimal，现金/费用精确到分。买入成本含买费，卖出按 FIFO 分摊成本并计算已实现盈亏；每个观察日强制核对：

`权益 = 现金 + 持仓市值 = 初始资金 + 累计已实现盈亏 + 当前未实现盈亏`

净值 = 权益 / 初始资金；累计收益 = 期末净值 - 1；回撤相对截至该日的权益高点（含初始资金），最大回撤为全曲线最小值。换手 = 累计买卖成交总额 / 所有观察日平均权益，双边累计、不年化；不将它与单边年度换手混用。

导出包括完整逐日曲线、信号/分值、目标与实际股数、订单状态/拒单原因、费用分项、FIFO批次、调仓后持仓历史及期末持仓。页面只截取最近50笔成交与50日账目，JSON保留全部；失败结果也持久化。

仍未支持动态池、退市结算、现金分红、送转拆并股、配股和完整公司行动。固定池有幸存者偏差；价格跳变会污染结果。合成验证只证明账目与规则，真实效果须在真实数据和独立组合协议上另行验收。

## API 与任务

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| POST | `/api/portfolio/demo` | 空对象；准备有合成标识的绑定数据与版本，不自动提交回放 |
| POST | `/api/portfolio/specs` | `experiment_id,factor_id,daily_id,execution_id`，可加 `name,parent_id,config` |
| GET | `/api/portfolio/specs` | 不可变版本列表 |
| POST | `/api/portfolio/runs` | `spec_id` 或 `replay_id` 二选一，可加 `timeout_seconds`；返回任务编号 |
| GET | `/api/portfolio/runs` | 结果索引（含失败，无大型报告） |
| GET | `/api/portfolio/runs/{id}` | 完整双账本或失败原因 |
| GET / POST | `/api/lab/jobs/{id}`、`/api/lab/control`、`/api/lab/retry` | 复用进度、取消和新建重试；portfolio不支持暂停 |

`portfolio` 为第四种持久化任务，仍按目录单工作进程串行执行，逐日检查停止与所有权，沿用超时和重启中断规则。输入校验失败后保存 `portfolio_run` 并标记任务失败；取消/超时可能尚无完整报告，不把部分账目当成功结果。重启不自动重放；备份须停机复制整个数据目录。
