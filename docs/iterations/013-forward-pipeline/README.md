## 范围和验收

- 将CSV/已下载日线追加、月度派生、单笔信号/成熟标签与组合前向账本串联为可审计后台任务。
- 自动运行默认关闭；显式启用后检测绑定来源的追加，持久化调度意图、防重复、重启不静默重放。
- 绑定启用版本和生效事件；实际生成时间留档，不回填历史信号。组合从新观察账户现金开始，固定订单仅在生成日期之后模拟执行，不继承最终回测持仓。
- 拒绝历史修订、回填、分支来源、固定池变化和旧引擎；数据质量/执行失败/待数据/样本不足/表现退化分列。
- 单元/恢复/并发/浏览器与CLI验证，并同步计划、设计和交接。真实行情/付费模型联测仍待本地条件，不交易、不自动更替、不自动提交推送。

## 实施与关键决策

- 新增 `quantify/pipeline.py`、`quantify/forward_portfolio.py` 和 `/forward` 页面。不可变流水线绑定来源根、当前引擎、冻结版本及启用事件，沿唯一后代链读取来源；任务队列新增 `pipeline` 类型，支持取消、超时、新建重试与重启恢复。
- 串联 CSV/已下载日线、按中国时间截取已完成数据、月度派生和前向观察。拒绝来源分支、历史修订/回填、固定池变化、不完整截面和不一致执行状态；日线7天/月度45天的新鲜度不足显示待数据。流水线消费已有来源，不自动开启行情下载。
- 单笔复用 `Lifecycle.signal/observe`，新增按启用事件隔离的信号键；回滚同一版本也不得复用旧事件信号、时间戳或标签。旧手动接口保留版本级历史。
- 组合从独立现金观察账户开始，按实际生成时间、当时可用数据与权益冻结股数。订单只在实际生成日期之后的首个完整日线模拟执行，支持待执行、整手、T+1、限价、停牌、费用及现金约束。重建只读取已保存的决策，禁止按历史月份补造信号。
- 实际决策估值端点形成不可变成熟段；候选和冻结参照在同期比较，按政策样本门槛区分不足样本与退化。报告校验历史净值、成交和订单前缀，不向模型自动反馈或自动更替因子。
- 显式调度默认关闭；开启后在中国工作日16:30后检查来源。持久化调度意图与队列事务双重去重；孤立意图、取消、中断、质量异常和执行失败需显式恢复。页面展示历史运行绑定的不可变报告，不用最新报告覆盖旧证据。
- 自查补齐：信号排序保证重复报告确定性；精确历史报告读取；单笔启用事件隔离；信号已提交而报告尚未提交时，重试仍核对该信号的原始输入，阻止利用中断绕过历史修订检查。
- 更新构建计划v14、使用指南、根目录交接和概要设计；新增流水线组件图与时序图，当前共27幅PlantUML图。
