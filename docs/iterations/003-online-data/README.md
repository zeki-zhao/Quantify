## 目标与决策

用户采纳复核后的方案：新浪 A 股行情快照、东方财富历史日线与每日增量、新增明确未含分红的价格收益研究模式。在线能力前置，不等待组合引擎完成。全部使用标准库，不引入 VS Code/Node 或第三方行情 SDK。

普通日线不能填入含分红再投资指数。新增独立字段 `close` 和 `monthly_price`，明确未复权、不含现金分红、公司行动跳变未调整。现有总回报模式继续严格使用 `total_return_index`。这让价格类因子可以使用真实价格序列，但不代表投资总回报或公司行动已处理。

## 实现

- `market_providers.py`：A 股代码规范化；新浪按代码解析 GBK 文本、保留行情/接收时间、逐股报错；东财检查代码/交易所/日期/OHLC、成交量手转股，固定未复权日线。白名单 HTTPS、默认 TLS、有限响应/超时/重试，不执行返回脚本。
- `market.py`：SQLite 设置、最近有效报价、失败/过期状态，后台轮询与有限退避；每日工作日中国时间 16:30 后最多一次下载，设置/提交标记跨重启保留。初始开关关闭。
- `jobs.py`、`lab.py`、`worker.py`：历史下载复用持久化队列和进程预算、查询/取消/重试；整批完成后保存日线快照，增量复核最近 7 天；新数据集和全区间复核可选，修订保留父版本和摘要。
- `datasets.py`、`research.py`、`factors.py`、`expressions.py`、`workbench.py`：独立价格字段/模式，月度派生，收益/因子按对应序列计算，协议记录口径；缺少分红指数不能悄悄走总回报。
- `research_tools.py`：AI 基线/结果/字段能力保留价格口径和来源警告，依旧不输出原始数据或封存收益；无财务字段不允许相应公式。
- `/market`：行情设置、时间戳、旧报价/错误、历史下载、调度与实际快照日期范围；工作台新增在线导航、价格 CSV 和月度收益口径选择；任务页展示下载进度。
- `market_probe.py`：只读在线诊断；接口任一失败返回退出码 1，区别代理/HTTP/超时/无效数据。命令与完整说明见 [MARKET_DATA.md](../../MARKET_DATA.md)。
