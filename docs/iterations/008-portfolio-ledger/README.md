# 008 · 组合账本与开发期回放

日期：2026-10-16（Asia/Shanghai）
状态：完成（P3.1基础 / 离线验收范围）
对应计划：P3.1 / A5 组合基础；计划更新为v9

## 目标与范围

用户要求执行下一阶段。真实行情与模型账户联测继续等待本地条件；本轮完成可离线验证的组合资金、持仓、月度调仓、执行限制、成本、净值和任务页面。

固定因子和参数可能已经用整个开发窗选择，因此组合结果定义为开发窗探索回放，不称为独立样本外组合成绩。本轮不读取最终留出收益，不继承005单笔最终验收/启用资格，也不接入AI自动组合准入或更替。

## 实现

- 新增 `portfolio.py`：Decimal资金、含买费成本、FIFO批次与T+1，100股整手，先卖后买；每个观察日校验 `权益 = 初始资金 + 已实现盈亏 + 未实现盈亏`。
- 每1/3/6/12个月在月度信号收盘固定目标股数，下一日线开盘模拟；未来开盘价只影响成交/现金能力，不扩大订单。失败订单与部分余量取消，最后无下一日线则明确未执行；终点持仓不强平。
- 显式 `execution` CSV：开盘前已知声明、停牌、上下限或明确无限价。缺失状态拒绝回放；零量/停牌/OHLC/限价/可用时间冲突拒绝，修订保留版本。下载日线不会自动获得可靠执行状态。
- 逐笔佣金（含最低佣金）、双边过户费、卖出印花税和不利滑点；费用是固定用户假设，滑点含于成交价内，不重复扣现金。
- `PortfolioService` 保存不可变 `portfolio_spec`，绑定成功开发实验中的固定因子、月度价格/未复权日线/状态快照、父版本、资金/成本/调仓与引擎；保存独立 `portfolio_run` 成功或失败结果。
- 第四种队列任务 `portfolio`：查询、取消、超时、重启中断、新建重试；逐日进度与所有权检查，同引擎固定版本可复现。
- 新增 `/portfolio` 页面：数据/版本/费用设置、固定种子合成准备、后台任务、筛选组合/等权全池双净值、现金与持仓、回撤、换手、费用、拒单原因、JSON导出和复现；导航及数据中心支持执行状态。
- 同步构建计划、交接、使用说明、数据契约和C4组件/产物/任务设计；新增组合模块图及回放流程图，概要设计共18幅PlantUML。

## 限制与下一步

1. 首版真实代码范围为沪深主板/创业板，统一100股单位；科创板/北交所、公司行动导致的零股尚未覆盖。保留固定股票池的幸存者偏差，暂无动态池与退市结算。
2. 价格收益不含现金分红，送转/拆并/配股跳变未处理；历史税率不会自动切换。没有盘口、排队、成交量参与率；滑点只是成本模型，拒单策略保守，不能当作真实撮合。
3. 没有真实交易日历核验；要求完整工作日观察截面，但不能识别所有缺失交易日、假日或伪造的停牌/限价。日期粒度的开盘前状态与日线可用时间由导入者声明，需要真实来源验收。
4. 组合版本只固定等权选股，不提供多因子版本引用和增量诊断；AI仍按单笔开发研究提案/准入，不会读取最终组合收益或直接启用。
5. 下一步推进A3/A4因子诊断/增量，或P3.2组合独立最终验收与人工更替；A6自动日线→月度→信号→成熟标签尚待。真实数据/模型联测待本地条件，不把本轮合成成绩用于效果承诺。
