## 实施与关键决策

- `model_api.py`：OpenAI Responses严格JSON Schema与DeepSeek Chat JSON对象；不依赖SDK；固定端点、TLS、无重定向、有限响应/I/O超时、安全错误。
- `model_calls.py`：job/round/attempt调用台账、预算预留/结算、成功提案缓存、未知结果拒绝静默重发；每轮只发送开发摘要、定义和反馈。
- `jobs.py`：接入调用表、停止/恢复时未知状态；API暂停继续回queued，阻止手动提案混入API会话。
- `lab.py`/`worker.py`：提供方/模型/单价/预算冻结，自动研究与既有本地引擎共用；API预算耗尽受控停止。
- `/lab`：新增模型设置、Key是否存在（不显示值）、提供方选择、预算、用量/估算费用和调用记录导出。
- 费用按用户声明单价估算，不是供应商硬限额；输入token用字节数+开销预留，超出报告按实记账并停止，不能声称绝对封顶。
- `tests/model_fixture_worker.py` 仅用于测试子进程的合成模型协议，不是应用运行开关，不绕过真实TLS或凭据。
