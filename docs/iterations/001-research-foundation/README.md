## 实施与关键决策

| 文件 | 变更 |
| --- | --- |
| `quantify/storage.py` | 内容摘要、不可变记录、SQLite 事务及重新打开后的读取 |
| `quantify/datasets.py` | CSV 契约、校验、增量、财务/股票池时点查询、日线转月度 |
| `quantify/factors.py` | 参数化因子注册、父子版本、固定类型计算；不执行用户代码 |
| `quantify/research.py` | 原有计算接入版本化因子，可选缺省财务输入、共同预热，保留旧入口结果 |
| `quantify/workbench.py` | 统一应用服务、实验留档/复现/对比、失败记录、留出协议 |
| `app.py`、`quantify/interfaces.py` | 新 API、静态页面、存储路径参数和适配契约 |
| `static/workspace.*`、`static/index.html` | 工作台与首页入口 |
| `tests/test_workspace.py` | 17 项数据、时点、版本、研究和 HTTP 测试 |
| `tests/browser_workspace.py` | 可选浏览器端到端检查，使用已有 Playwright 与 Chromium |
| `.gitignore` | 忽略本地 `runtime/` 数据 |

先采用 SQLite 保存含原始输入的快照，便于原子写入、迁移与复现；尚未引入 Parquet、数据服务 SDK 或前端框架。运行时仍然零第三方依赖。

固定 30 个月预热覆盖最大窗口 24 月与跳过 6 月，避免新旧因子因测试起点不同而直接比较。封存 12 个月时，3/6/12 月持有期至少需要 86/92/104 个月数据，界面与说明均告知。

## 限制

- CSV 的来源、总回报口径和时间由用户声明，程序只验证结构和逻辑一致性；未核验公告或数据授权。
- 财务表输入为质量/价值因子，不是完整财报；没有真实财务覆盖验收。
- 历史股票池可查询，当前研究仍要求固定池，不支持退市结算；遇到动态池不静默删股。
- 交易日历尚未接入，日线转月度取最后观测日并舍弃最后日历月，不保证完整月份。
- 留出期没有被本次计算，但本地用户可查看原始快照；无最终独立验收或 AI 权限隔离。
- 长任务仍同步执行；没有 AI 接入、自动数据下载或自动因子启用。
- 复现时需保留对应代码环境；代码指纹改变将拒绝把新引擎运行称为原实验复现。
