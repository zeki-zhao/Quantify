## 目标与依赖

用户要求在第一阶段没有问题的情况下执行第二阶段。开始前复核原 40 项测试全部通过，随后建设持久化任务、受限公式、统一研究工具、有限轮次提案/实验/反馈与研究室页面。

用户明确选择“第二种”：**手动粘贴 ChatGPT 提案，保留 API 接口**。因此当前不接远程模型、不需要密钥，也不把一次批量提案执行称作模型自主生成的闭环。可由用户将每轮实际反馈交回 ChatGPT，再继续提交。

P1.2 的在线来源、真实覆盖、动态池和退市限制保留；它们不阻塞合成/固定池 CSV 的第二阶段基础设施，但不能据此声称真实研究已完成。

## 实现

- `jobs.py`：SQLite 任务与追加事件、单目录文件锁、串行计算子进程、状态/时限/暂停/继续/取消/中断、新任务重试。重启不自动重跑，旧任务与预算保留；重试有新编号和新预算。
- `expressions.py`、`factors.py`：受限 AST 向量解释器，质量/价值、过去窗口动量/波动、截面排名/标准化与四则运算；限制长度/节点/深度/数值，拒绝未来窗口、任意代码、除零和缺字段。
- `research_tools.py`：会话范围工具，锁定基线数据/成本/持有期/引擎，只输出开发窗摘要和因子定义，不提供原始行情与封存期收益。
- `proposals.py`、`lab.py`、`worker.py`：严格 JSON 提案、手动提供方与未来 API 契约、协作包、轮次/候选/累计计算时间/无改进预算、不可变候选与真实引擎实验、准入比较与研究建议。
- `/lab`：会话创建、后台任务、上下文/反馈下载、提案粘贴、每轮公式与指标、控制和日志导出；`/workspace` 新实验/复现进入队列，因子库支持公式派生。
- 暂停检查点包含待处理轮次与确定实验编号；实验已入库而任务记录未完成时，继续会复用实验，避免重复计算和重复计数。
- 更新 README、HANDOFF、agnet、构建计划 v3、文档入口和迭代索引；操作说明新增 `docs/AI_RESEARCH.md`。

选择规则是平均单笔净收益相对当前最佳严格改善，同时最差单笔收益满足相对原基线的限制，样本量与协议一致。输出保留上涨比例、均值、尾部、样本量和分窗结果。自然语言目标只用于假设解释，不自动实现组合指标；最终建议不启用策略。

- 代码摘要变化后旧 P1 实验仅供查看，需要按相同参数新跑当前引擎基线；不篡改历史记录。
- P1.2 仍部分完成，最终留出验证入口、策略启用、组合资金/成交、动态池/退市与实时数据未实现。
