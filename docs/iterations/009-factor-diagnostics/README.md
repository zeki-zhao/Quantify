## 实现与统计边界

- 新增 `diagnostics.py` 纯计算：输入/分值覆盖、Spearman Rank IC、同分保留的分组净收益、高低组差、分年/测试块稳定性及因子成对秩相关；显示有效窗口和共同样本。
- 直接截除源快照最终留出，仅使用源实验实际的非重叠成熟开发测试信号窗，沿用延迟入场、持有期与费用。因子输入只到信号日，独立最终验证不受诊断替代。
- 并列取平均秩，不按代码拆组；常数/配对不足/空组为null，字段或公式错误整截面拒算并留原因，不补零、不删股票。IC均值与高低组差等权按窗，分组收益等权按股票×窗口；没有年化/ICIR/显著性或可交易多空净值宣称。
- 新增 `DiagnosticService`、第五种 `diagnostic` 任务及 `/diagnostics` 页面：固定实验/因子/组数/引擎，不可覆盖报告、缓存复现、查询/取消/超时/新建重试和导出。全部因子不可计算时报告可生成，但计算覆盖率为0，不标记因子有效。
- `trial_audit.py` 在单个读事务内只读experiment/factor元数据、research进度与消费事件，按会话+轮次合并，不扫描无关行情/组合大报告；全目录与同协议分开。收益实验状态、重放/重复、候选消费/非法/未完成/停止、未消费提案及重复定义均可查询；诊断不增加收益实验次数。
- 新增会话作用域内 `get_factor_diagnostics`，默认原基线首因子与指定实验首因子在同窗诊断。手动协作包、双API上下文和每轮成功候选反馈（含未获准入者）附受限摘要及同协议计数；API再次按字段白名单裁剪，无原始行情/逐股分值收益/留出/外会话个别指标。
- 原目标与准入政策不变；诊断不可用不会单独改变原候选判优。新增上下文仍受原模型预算与网络前预留约束，不增加额外模型请求。
- 同步构建计划、README/交接、使用说明与C4/模块/产物/任务/流程；新增诊断模块与流程两幅PlantUML，当前共20幅图。
