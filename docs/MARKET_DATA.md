# 在线行情、历史日线与价格收益

更新日期：2026-10-15（Asia/Shanghai），迭代 003。

当前实现新浪 A 股快照、东财未复权日线、手动/每日增量调度和月度价格收益研究。全部为 Python 标准库，无需安装 VS Code 插件、AKShare 或 efinance，该行情通路本身不调用模型；可选API研究的配置与费用估算另见[模型API](MODEL_API.md)。真实接口的覆盖、延迟、权限与持续可用性需要单独验收。

**本次云环境联网验收受阻**：新浪和东财均在代理建立 HTTPS 隧道时返回 403，没有取得真实行情。接口解析、存储、队列、研究与浏览器测试通过不能替代供应商联网验证。代理错误不是数据服务额度用尽的证据；已保存 [本次探测结果](iterations/003-online-data/online-check.json)。

## 从哪里进入

运行 `python app.py`，在工作台导航选择“在线行情与下载”（`/market`）。初次启动的行情刷新、每日更新开关均为关闭，不发起行情请求。

1. 保存自选股代码，例如 `600519.SH, 000001.SZ`。支持带后缀、`sh600519` 或六位 A 股代码，当前最多 30 只；不包含指数、港美股与期货。
2. 点击“查询一次行情”，或开启定时查询。报价显示行情时间、接收时间、最新价格、日内累计成交量、状态与错误。
3. 保存用于历史研究的股票列表（当前研究至少 3 只）和起始日期，设置截止日，点击“提交历史下载任务”。在 AI 研究室的后台任务中查询或取消，失败可新建重试。
4. 下载成功后，返回工作台，从日线生成月度研究数据，选择“价格收益（未复权、不含分红）”。选择动量/低波动或只依赖价格的公式，运行实验。
5. 实验成功后可作为 AI 研究室基线。协作包保留价格收益口径、数据警告和版本，提案不能访问原始行情或封存期收益。

CSV 导入仍可补充数据。财务因子没有在本轮自动下载；缺少 `quality/value` 时相应因子会拒绝运行，不填零。默认封存 12 月，3/6/12 月持有期至少需要 86/92/104 个连续月度截面；日线转月度还会舍弃最后一个日历月，因此下载历史需要更长。

## 实时快照的边界

- 新浪接口：`https://hq.sinajs.cn/`，按股票代码批量查询；请求使用新浪财经 Referer，GBK 解码，白名单解析文本赋值，不执行返回的 JavaScript。实现参考 [Stock Bar 的请求方式](https://github.com/Chef5/stock-bar/blob/main/src/provider.ts)。
- 默认查询间隔 10 秒，最低 5 秒。这是本地轮询设置，不是供应商延迟保证，不等于逐笔 Tick 或实时推送。
- 行情时间按中国时间解析，接收时间独立保存；迟到行情、重复/未请求代码、非法数值和零价格会拒绝或逐股报错。按代码匹配响应，不依赖返回顺序。
- 查询失败时保留旧报价，明确标记获取失败；不会更新旧报价的行情时间。交易时段内报价年龄超过 `max(30 秒, 2 × 配置间隔)` 则标记过期。
- 自动查询在估计的交易时段执行；非交易时段启用/重启后最多先查一次，再保留最近报价。工作日和时段只是估计，没有节假日交易日历；休市时的报价不标记为新成交。
- 网络请求每次超时 6 秒，最多 2 次尝试；代理拒绝及普通 HTTP 4xx 不反复重试，429/5xx 有限重试。连续失败逐步退避，最长 5 分钟。手动请求也有最短间隔。
- SQLite 保存最近有效报价与最近请求结果，未建设逐笔或秒级历史仓库；当前只适合自选股监测，不承诺全市场低延迟分发。

## 历史下载、增量与调度

东财接口：`https://push2his.eastmoney.com/api/qt/stock/kline/get`，固定日线 `klt=101`、不复权 `fqt=0`。字段映射参考 [AKShare 实现](https://github.com/akfamily/akshare/blob/master/akshare/stock_feature/stock_hist_em.py)。成交量从手转换为股，OHLC 为元/股；不生成含分红指数。

一批最多 30 只、日期跨度最多 20 年，同时受既有 8 MB CSV/10 万行快照上限约束，较长区间应减少股票数。每只股票响应核对代码、交易所、日期范围、重复日期与 OHLC，所有请求都成功校验后才保存一个日线快照；任一股票失败则整批不导入，避免静默缩小股票池。

单批响应上限 2 MB，队列计算进程时间预算 600 秒，可取消。存储前写入检查点。停止边界若已保存快照而任务未完成，该快照仍保留；任务状态独立记录，不删除审计记录。成功任务记录快照 ID，并更新在线数据入口当前快照。

- **增量**：选择当前东财快照作父版本，从其最后日期向前 7 天重新检查，再追加到截止日。内容没变化返回原快照；修订建立新版本，旧记录可读。
- **全区间复核**：重新下载设定区间并合并到父版本，用于发现 7 天以外的历史修订。不会根据远端缺行删除本地旧行，也不能把合并行为当成完整性验收。
- **新数据集**：父版本为空。更换股票列表或需要重建系列时使用；快照列表仍保留旧数据集。
- **每日更新**：明确开启后，在应用持续运行的中国时间工作日 16:30 后，每日最多提交一次任务。首次可补历史，其后使用增量；当前未核验交易节假日，休市可能返回没有新增数据的快照。
- **重启**：定时配置和当日提交标记持久化，排队/运行任务按既有规则标为中断，不自动重跑旧任务；以后日期仍按开启的计划新建更新。提交意图先落库，异常时可能当日没有实际提交，可手动补发，避免崩溃造成重复循环。

不导入尚未完成的当日日线：当日仅在中国时间 16:30 后允许请求，周末按最近工作日估计。没有交易日历时，这不保证停牌、退市或实际应有交易日均完整。

快照保留请求/实际返回区间、接收时间、响应 SHA-256 和供应商标识。`available_at` 的价格日期假设为当日收盘可用，获取的是本次供应商提供的历史版本，并非当年原始版本档案。这个限制会传播到月度快照、报告和 AI 协作包。

## 价格收益与总回报独立

新类型 `monthly_price` 使用独立字段：

```csv
date,symbol,close,quality,value,available_at
```

只接受 `price_basis=unadjusted`。收益为退出收盘价/入场收盘价 − 1 − 往返成本。现金分红未计入，拆股、送转、配股等除权跳变未调整，会影响动量、波动和收益统计；结果是价格序列研究，不代表持有人的完整投资回报。若研究需要消除这些影响，应先补可靠公司行动和分红数据。

现有 `monthly` 类型和 `total_return_index` 字段继续表示含分红再投资总回报；程序不会将价格填入这个字段，也不把 `qfq/hfq` 自动等同总回报。模式由快照类型决定，因子内部按相应序列计算，不能直接比较不同快照/收益口径的实验。

日期边界、共同预热、训练标签成熟检查、同窗成本、最终封存与固定股票池限制保持适用。报告、因子比较、导出和 AI 上下文均保留 `return_basis`。公式/数据代码变更影响引擎摘要；旧实验可查看，需要新跑当前引擎基线后继续迭代。

## 本机联网诊断

在允许访问数据源的电脑上执行（只读，不写入数据库）：

```powershell
python -m quantify.market_probe --symbol 600519.SH
```

可加 `--start YYYY-MM-DD --end YYYY-MM-DD`。两项成功才返回退出码 0；任一失败返回 1，JSON 区分代理、HTTP、超时、数据格式及空报价错误。成功仅说明当前请求可用，历史覆盖、公司行动、北交所覆盖及延迟仍需逐项核验。

若切换到本机执行，并有可用的 HTTP 代理，可在启动应用的同一个 PowerShell 终端设置：

```powershell
$env:HTTP_PROXY = "http://127.0.0.1:7890"
$env:HTTPS_PROXY = "http://127.0.0.1:7890"
python -m quantify.market_probe --symbol 600519.SH
python app.py
```

7890 是示例端口，请使用代理软件实际的 HTTP 或 mixed 端口；标准库不直接支持仅 SOCKS5 的代理端口。需要切换实际命令执行环境到本机，只在本地打开聊天界面仍可能由云端执行。`127.0.0.1` 指向命令所在机器，云端不能直接连接用户电脑上的本地代理。是否可用以探测结果为准，代理无法解决供应商的账号权限或接口失效。不要把代理凭据写入 Git 或聊天。

云环境需要允许 HTTPS 访问 `hq.sinajs.cn` 和 `push2his.eastmoney.com`。浏览器与服务器的网络位置可能不同，VS Code 插件在本机可用不能证明云端可用。当前适配器只访问这两个固定 HTTPS 地址，不接受自定义网络目标，不跟随重定向，不禁用 TLS 验证。
