模型 API 配置

密钥仅从启动应用的环境变量读取：OPENAI_API_KEY / DEEPSEEK_API_KEY，设置后重启应用。此页面不接收或显示密钥；ChatGPT订阅不等于API额度。模型名称以账户实际可用为准。

预算采用你声明的单价估算，缓存输入按未缓存单价保守计算，不含币种换算，也不是供应商账单硬限额。保存配置不会调用远程模型；运行中的会话使用创建时冻结的配置。

创建研究任务

先在研究工作台运行基线实验。旧引擎实验需按原参数重新运行；基线锁定快照、成本、持有期和封存期。每个候选单独检验。

API 调用预算（每次请求先预留，重试也计数）

超时、断线和进程中断可能已在远端产生费用，保留预留且不自动重发。仅明确的429/5xx可在所设次数内重试；每次仍须取得新预算。API会话自动提出下一轮假设，模型不能运行任意工具或启用版本。

主目标、均值/尾部约束和样本门槛继承基线的结构化配置，同时检查当前最佳和原基线。默认主目标为上涨比例，严格改善才接受；额外约束只会收紧门槛。等待粘贴的时间不计入运行时限。自然语言目标用于解释假设。

后台任务

关闭页面不影响任务。单次实验和研究任务串行执行；暂停、取消或时限到达会停止计算进程。服务重启会将排队/运行任务标记为中断，重试创建新的记录和预算；API新建重试可能再次计费，旧调用与费用记录保留。
